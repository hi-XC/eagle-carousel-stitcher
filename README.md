# 轮播拼接 · 0.3.0

将 Eagle 中选中的图片、视频或两者混合横向或纵向拼接为新素材，适合还原社交平台的连续轮播图。

界面随 Eagle 语言设置选择简体中文或英文；其他语言使用英文。修改语言后重新打开插件。

## 使用

1. 在 Eagle 中选中图片或视频，再打开「轮播拼接」；也可先打开插件，再读取或拖入选中的素材。视频缩略图和预览显示首帧。
2. 需要补图时，在 Eagle 中选中图片后拖入插件左侧区域，或点击图片列表后的加号。重复的素材不会重复添加。点击加号旁的清空按钮并确认后，可移除插件中的整组选图和编辑信息；Eagle 中的素材不受清空操作影响。
3. 选择方向，通过图片缩略图选择切片，再在预览下方调整它与前一张的重叠像素。缩略图上的箭头用于调整顺序，悬停可移除图片。改变顺序或方向会重置重叠值，并在界面提示。
4. 检查名称、标签、文件夹、来源、备注和评分。有视频时，可在「声音」中选择静音或其中一段有音轨的视频。默认带入全部原素材标签和共有文件夹；文件夹不同时需要确认目标位置，也可以不选择文件夹。
5. 点击「拼接并导入」。新素材成功导入且文件、名称、所选标签、文件夹、来源、备注和评分核验通过后，原素材才逐一移入 Eagle 回收站。失败时界面会提示；部分原素材未能移动时请在 Eagle 中检查。原素材可以从回收站恢复。

纯图片生成 PNG，不拉伸素材，不同尺寸按顶部或左侧对齐，空白区域透明。每项素材的重叠值从其左侧或顶部裁切。输出限制单边 32767 像素、总计 1 亿像素；实际可用大小还取决于设备内存。预览为缩略图，视频显示首帧。

有视频时输出 H.264 MP4（30 fps），时长与最长视频一致；较短视频停在最后一帧，图片保持静止。默认静音，可选择一段视频的声音，短音轨结束后为静音。视频画布的空白区域为黑色，输出尺寸会补齐到偶数。视频需要 Eagle 官方 FFmpeg 依赖。

本版不处理 GIF、APNG 或动态 WebP。无法解码或导出失败时会提示错误，原素材不会被移动。读取与导出完全在本地进行。

## 安装与测试

双击 `.eagleplugin` 安装，或在 Eagle 开发者模式加载 `Plugin` 目录。先使用可恢复的测试素材验证自己的 Eagle 版本与素材格式，再处理正式素材。视频功能使用 Eagle 官方 FFmpeg 依赖，不依赖下载器。

安装 Node.js 后，在项目目录执行 `npm install`，然后用 `npm run build` 构建、`npm test` 运行测试。Eagle 真机验证需要在 Eagle 内安装或加载本插件。
